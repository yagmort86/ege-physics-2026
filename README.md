# 📘 ЕГЭ 2026. Физика — Интерактивное офлайн-пособие

Интерактивное автономное веб-пособие по физике для подготовки к ЕГЭ 2026 на основе книги **«Отличный результат» (под ред. М. Ю. Демидовой)**, 488 страниц.

Разработано специально для комфортного решения заданий ребенком в домашней локальной сети (Wi-Fi) **без необходимости доступа во внешний интернет**.

---

## 🚀 Быстрый старт

### 1. Запуск на компьютере родителя
Дважды кликните по файлу **`run_server.bat`** (или выполните в терминале `python run_server.py`).

В консоли отобразится информация:
```text
================================================================
  📘 Интерактивное пособие: ЕГЭ 2026 Физика (Демидова М.Ю.)
================================================================
  🟢 Локальный сервер запущен и готов к работе!

  💻 На этом компьютере:
     http://localhost:8080

  📱 Ссылка для ребенка в домашней сети (Wi-Fi):
     http://192.168.1.XX:8080

  ℹ️ Интернет не требуется: сервер работает автономно.
================================================================
```

### 2. Подключение ребенка
Отправьте ссылку вида `http://192.168.1.XX:8080` ребенку на планшет, ноутбук или смартфон.
Пособие мгновенно откроется в любом браузере даже при выключенном на роутере интернете.

## 🎯 Основные возможности

1. **Интерактивное древовидное оглавление**:
   - Быстрый переход по всем разделам и темам:
     - *Справочные данные и формулы (стр. 2–3)*
     - *Входная диагностическая работа (стр. 4–10)*
     - *Раздел 1. Механика (Кинематика, Динамика, Статика, Законы сохранения, Колебания)*
     - *Раздел 2. Молекулярная физика и термодинамика*
     - *Раздел 3. Электродинамика и оптика*
     - *Раздел 4. Квантовая физика*
     - *Раздел 5. Итоговый контроль (Варианты 1–3)*
     - *Раздел 6. Ответы, решения и критерии оценивания (стр. 424–488)*
   - Живой поиск по темам.

2. **Высококачественный просмотрщик страниц**:
   - 488 страниц в оптимизированном формате WebP высокого разрешения (1600px).
   - Плавное масштабирование (Zoom: 50% – 300%, по ширине, по высоте).
   - Режим книжного разворота (две страницы рядом) или одна страница.
   - Перелистывание колесиком мыши, ползунком снизу или горячими клавишами.
   - Предзагрузка соседних страниц для мгновенного отклика без задержек.

3. **Интерактивная панель решений и проверка ответов**:
   - Активные поля ввода для задач текущей страницы.
   - **Мгновенная проверка**:
     - 🟢 *Верно* (полный балл)
     - 🟡 *Частично верно* (1 ошибка в заданиях на соответствие/множественный выбор)
     - 🔴 *Неверно* (с предложением попробовать еще раз или открыть подсказку)
   - Поддержка гибкого ввода: принимаются запятые и точки (`0,25` и `0.25`), последовательности цифр (`124` и `1 2 4`), отрицательные числа.
   - Возможность добавить любое свое задание на страницу кнопкой `+ Добавить задание`.

4. **Система подсказок и решений**:
   - Кнопка **«💡 Подсказка»** с указанием физического принципа или нужной формулы.
   - Кнопка **«📖 Ответы к теме»** открывает официальный лист ответов и критериев из конца книги в удобном всплывающем окне без потери текущей страницы.
   - Встроенный справочник основных формул по механике, МКТ, электродинамике, оптике и квантовой физике.

5. **Автономное сохранение и статистика**:
   - Все введенные ответы, заметки и закладки автоматически сохраняются в `localStorage` браузера ребенка.
   - Кнопка **«Прогресс»**: статистика решенных заданий, процент точности, список закладок.
   - Экспорт/импорт результатов в файл JSON (родитель может сохранить или перенести прогресс).

6. **Режимы работы**:
   - 🎓 **Режим ученика** — правильные ответы скрыты, доступны подсказки и проверка.
   - 👁️ **Режим родителя** — сразу отображает эталонные ответы для быстрой проверки.
   - ☀️ / 🌙 Светлая и тёмная темы оформления.

---

## ⌨️ Горячие клавиши

- `←` / `PageUp`: Предыдущая страница
- `→` / `PageDown`: Следующая страница
- `Home` / `End`: Первая / последняя страница
- `+` / `-`: Приблизить / отдалить
- `0`: Сбросить масштаб
- `D`: Переключить режим 1 или 2 страницы
- `Esc`: Закрыть всплывающие окна
